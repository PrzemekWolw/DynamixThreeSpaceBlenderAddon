# Dynamix Three SpaceBlender Addon
Import Dynamix Three Space (DTS) models from Torque3D and BeamNG.drive into Blender
It can import 2 UV channels, vertex colors, object position and rotation, level of detail and collisons.

It can import material names, but material parameters (such as color) are not currently imported

## Version Support
Versions 19, 20, 21, 22, 23, 24, 25, 26, 29 and 31 should function.

The code is based off the Torque3D source code so adding in newer versions should be relatively easy

## Installation
1. Grab the latest `io_scene_dtst3d.zip` here https://github.com/PrzemekWolw/DynamixThreeSpaceBlenderAddon/releases
2. In Blender, select Edit > Preferences
3. Select the Add-Ons tab
4. Click Install in the top right corner
5. Select the ZIP file


**Important:** The add-on was developed on Blender 4.5. Should support Blender 3.6 as well. While it's not a strict requirement you use this version, other versions may not work correctly.
